# JazzHQ Channel Management Software Buyer’s Guide

A standalone Next.js App Router site for **Channel Management Software: The Best 8 Platforms Compared**. The article lives at `/buyers-guide/channel-management-software`; the root redirects to it.

Use Node 20.9 or later.

```sh
npm ci
npm run dev
```

Run `npm run lint`, `npm run typecheck`, and `npm run build` before sharing a preview. Run `npm start` to serve the production build.

The article remains **noindex** pending editorial approval. `NEXT_PUBLIC_SITE_URL` can be set to an approved origin when one is assigned. The editorial review records facts to resolve separately from the PDF copy. The eight WebP screenshots are from the PDF.

The header, footer, grid, and branding derive from the approved Euler Alternatives reference. Unavailable legacy destinations retain their labels; an approved Alternatives origin can be supplied through `NEXT_PUBLIC_ALTERNATIVES_ORIGIN`. No existing Alternatives article or Git history is included. The bundled Inter font license is in `src/app/fonts/OFL.txt`.
